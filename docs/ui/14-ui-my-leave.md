# UI 與流程設計：我的資料／請假與餘額

## 確認狀態

本文件內容已由使用者明確同意，列為正式 UI、流程與資料責任規劃。

## 導覽結構

```text
我的資料
├─ 個資
├─ 出勤紀錄
├─ 補打卡申請
└─ 請假與餘額
```

頁面分為「假期餘額」與「請假紀錄」兩個頁籤，右上方提供新增請假申請。

## 假期餘額

必須顯示每一次實際發放，不得只顯示假別總額：

| 假別 | 發放來源 | 發放日期 | 可用期間 | 發放時數 | 申請中 | 已使用 | 剩餘 | 狀態 |
| ---- | -------- | -------- | -------- | -------: | -----: | -----: | ---: | ---- |

- 顯示特休、補休、福利假及其他需要額度的假別。
- 發放來源依類型顯示年資／制度、加班申請或公司贈與批次。
- 原始發放時數不得因使用而修改。
- 狀態支援尚未生效、有效、已用完、已到期、已撤銷及已結清。
- 已到期及已撤銷紀錄仍保留。
- 預設顯示有效額度，可選擇包含歷史額度。

資料來源：

- 特休、福利假等一般額度：`leave_entitlements` 與 `leave_balance_transactions`。
- 補休：`compensatory_leave_credits` 與 `compensatory_leave_transactions`。
- UI 可統一顯示，但補休與一般假別不得合併為同一資料帳本。
- `leave_balances` 是假別總額快取，不能取代每次發放明細。

## 請假紀錄

| 申請日期 | 假別 | 請假起訖 | 請假時數 | 事由 | 狀態 | 操作 |
| -------- | ---- | -------- | -------: | ---- | ---- | ---- |

狀態包含待審核、已核准、未核准、已撤回及已取消。查看明細時顯示完整日期、時段、額度扣抵來源及審核歷程。

## 新增請假申請

| 欄位         | 必填性     | 說明                     |
| ------------ | ---------- | ------------------------ |
| 請假類別     | 必填       | 目前可申請的假別         |
| 開始日期     | 必填       | 請假開始工作日           |
| 結束日期     | 必填       | 請假結束工作日           |
| 指定請假時段 | 選填開關   | 開啟後顯示開始與結束時間 |
| 開始時間     | 開啟時必填 | 指定時段開始時間         |
| 結束時間     | 開啟時必填 | 指定時段結束時間         |
| 請假時數     | 系統計算   | 依班表、日期與時間計算   |
| 事由         | 必填       | 請假原因                 |
| 證明文件     | 依假別規則 | 需要證明的假別才顯示     |

### 整日與指定時段

- 預設為整日請假。
- 開啟「指定請假時段」後可選擇幾點到幾點。
- 員工不可直接輸入總請假時數。
- 全天依每日應工作時段計算。
- 指定時段需扣除不計工時的休息時間。
- 跨多日依每天班表拆成 `leave_request_details`。
- 休假日或沒有排班的日期不計入請假時數。
- 跨日班依實際班表時段計算。
- 送出前顯示計算後總請假時數。

## 額度檢查與扣抵

- 顯示申請時數、目前可用時數及申請後剩餘時數。
- 需要額度的假別，餘額不足不能送出。
- 待審核申請先凍結額度。
- 撤回或未核准時原路返還凍結額度。
- 核准後由凍結轉為已使用。
- 自動優先使用最早到期的有效額度。
- 一張申請可由多筆發放額度共同扣抵。
- `leave_request_allocations` 保存實際扣抵來源。
- 補休只扣補休來源，不與特休或福利假混用。

## 送出檢查

- 結束時間必須晚於開始時間。
- 不可申請沒有班表且不需請假的時段。
- 不可與本人待審核或已核准請假時段重疊。
- 需要額度的假別必須有足夠有效餘額。
- 已到期、已撤銷及尚未生效額度不可使用。
- 需要證明文件時必須依規則提供。
- 已結算月份不得新增請假申請。

## Schema 對應

- `leave_requests`：申請主檔、事由及狀態。
- `leave_request_details`：每天／時段起訖與分鐘數。
- `leave_request_allocations`：額度扣抵來源。
- `leave_request_approvals`：流程歷程。
- `leave_request_documents`：證明附件。
- `leave_entitlements`：特休與福利假等逐筆發放。
- `compensatory_leave_credits`：逐筆補休額度。
