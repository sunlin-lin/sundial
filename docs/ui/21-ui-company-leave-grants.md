# UI 設計規劃：特休／補休贈與

## 確認狀態

本文件內容已由使用者明確同意，列為正式 UI 規劃。

## 導覽結構

> 選單位置：`人事作業 → 特休／補休贈與`

```text
人事作業
├─ 員工清單
├─ 組織架構
├─ 全體出勤
└─ 特休／補休贈與
```

本功能由公司主動發放特休或補休給員工，不是員工互相轉贈，也不是一般請假申請。

## 主畫面

主畫面預設顯示「發放列表」，右上角提供「新增發放」。列表以每位受贈員工為一筆，不以批次為一筆，讓管理者直接看見發給誰、發了什麼。

### 查詢條件

- 發放日期區間
- 假別：全部、特休、補休
- 部門
- 員工編號或姓名
- 有薪／無薪
- 發放狀態
- 發放批次編號

預設依發放時間由新到舊排序，每頁20筆。

## 發放列表

| 欄位       | 顯示內容           |
| ---------- | ------------------ |
| 發放日期   | 實際發放日期及時間 |
| 發放批次   | 所屬批次編號       |
| 員工編號   | 受贈員工編號       |
| 員工姓名   | 受贈員工姓名       |
| 部門       | 發放當時所屬部門   |
| 假別       | 特休或補休         |
| 贈與時數   | 原始發放時數       |
| 有薪／無薪 | 有薪或無薪         |
| 可用期間   | 開始日期至結束日期 |
| 已使用     | 已抵扣時數         |
| 剩餘       | 尚未使用時數       |
| 撤銷時數   | 已撤銷的未使用時數 |
| 發放原因   | 公司發放原因       |
| 發放者     | 執行發放的人員     |
| 狀態       | 發放與使用狀態     |
| 操作       | 查看明細、撤銷發放 |

狀態包含：可使用、部分使用、已用完、已到期、已撤銷、部分撤銷、發放失敗。

## 新增發放

支援個別發放及批次發放。批次發放可以依部門選擇或自行勾選多名員工。

| 欄位       | 必填性 | 規則               |
| ---------- | ------ | ------------------ |
| 發放對象   | 必填   | 單一或多名員工     |
| 假別       | 必填   | 特休或補休         |
| 贈與時數   | 必填   | 必須大於0          |
| 有薪／無薪 | 必填   | 1 有薪、2 無薪     |
| 開始日期   | 必填   | 額度開始可使用日期 |
| 結束日期   | 必填   | 不得早於開始日期   |
| 發放原因   | 必填   | 公司發放原因       |
| 備註       | 選填   | 公司內部說明       |

送出前顯示假別、人數、每人時數、薪別及有效期間摘要。

## 批次處理結果

- 逐一顯示每位員工的成功或失敗結果。
- 批次發放允許部分成功。
- 成功員工立即取得額度。
- 失敗員工顯示原因並可單獨重新發放。
- 重試失敗名單時，不得重複發放給已成功員工。

## 查看明細

明細顯示批次編號、員工、發放當時部門、假別、原始時數、薪別、有效期間、原因、備註、發放者、發放時間、已使用、剩餘、到期、撤銷時數、相關請假抵扣及額度異動歷程。

失敗時顯示失敗原因；撤銷後顯示撤銷者、撤銷時間與撤銷原因。

## 撤銷發放

撤銷以個別員工發放紀錄為單位，不連帶影響同批次其他員工。

撤銷確認畫面顯示員工、假別、原發放時數、已使用時數與可撤銷時數，並要求填寫必填的撤銷原因。

### 撤銷規則

- 尚未使用：撤銷全部時數。
- 已部分使用：只撤銷剩餘未使用時數，已使用請假不受影響。
- 已全部使用：不可撤銷。
- 已到期但仍有剩餘：可以撤銷剩餘時數。
- 已撤銷：不可再次撤銷。
- 已完成薪資結算或已轉成薪資：不可撤銷。
- 撤銷後不能恢復原發放，只能重新發放。
- 不刪除原始發放、使用或撤銷紀錄。

## Schema 對應

| Schema                          | UI責任                         |
| ------------------------------- | ------------------------------ |
| `company_leave_grant_batches`   | 發放批次及共同條件             |
| `company_leave_grants`          | 每位員工的發放、結果及撤銷資料 |
| `leave_types`                   | 可發放假別                     |
| `leave_entitlements`            | 成功發放後的可用額度           |
| `leave_balance_transactions`    | 核發、使用、到期及撤銷交易     |
| `employees`                     | 受贈員工                       |
| `employee_department_histories` | 發放當時部門                   |

欄位、關聯與約束以 [加班、補休、請假及公司贈與假 Schema](../schema/04-overtime-leave.md) 為準。
