# 薪資作業／薪資試算與結算（已確認）

## 導覽

```text
薪資作業
└─ 薪資試算與結算
```

## 月份與狀態

- 進入後預設顯示當月，可切換年月。
- 當月尚未生成：只顯示「生成試算」。
- 已生成且未結算：直接顯示最新結果，不需要按查看；可重新生成、修改薪資及結算。
- 已結算：直接顯示鎖定結果；不可重新生成或修改，只能撤銷結算。
- 撤銷後：保留目前結果，可修改、重新生成或直接再次結算。
- 每次首次生成或重新生成均建立新版本。
- 每次生成、重新生成、結算及撤銷均保留歷程；撤銷原因必填。

## 統計

生成後，上方依序顯示：

| 人數 | 應發合計 | 員工代扣 | 實發合計 | 雇主負擔 | 公司總成本 |
| ---- | -------- | -------- | -------- | -------- | ---------- |

```text
實發＝應發－員工代扣
公司總成本＝應發＋雇主負擔
```

## 員工列表

每頁20筆。

| 工號 | 姓名 | 應發 | 代扣 | 實發 | 雇主負擔 | 公司總成本 | 狀態 |
| ---- | ---- | ---- | ---- | ---- | -------- | ---------- | ---- |

- 可依工號、姓名、部門及狀態查詢。
- 每筆可直接展開薪資內容。
- 狀態分為正常、警告及異常；存在阻擋型異常時不得結算。

## 展開內容

- 員工常駐薪資項目（唯讀）
- 當期臨時加發
- 當期臨時扣款
- 員工代扣
- 雇主負擔
- 應發、代扣、實發及公司總成本摘要
- 警告與異常原因

## 當期臨時薪資項目

- 試算生成後、結算前才可新增或修改。
- 不修改、不回寫員工常駐薪資設定。
- 只屬於當期，不自動帶到下月。
- 每位員工的臨時項目數量不限。
- 可逐筆修改或撤銷；撤銷保留歷程。
- 結算後全部鎖定，必須先撤銷結算才能修改。

### 套用對象

- 全體員工
- 複選部門
- 部門可選擇包含下層部門
- 指定一位或多位員工
- 先選部門再排除或加入個別員工

部門人員範圍以該薪資月份的有效組織歸屬判定。同一次批次中，同一員工重複被選取時只納入一次。

### 計算方式

- 固定金額
- 逐人輸入
- 單一薪資基底 × 倍數
- 單一薪資基底 × 比率
- 多項薪資基底合計 × 倍數
- 系統計算後覆寫個別最終金額

例如：

```text
年終獎金＝基本工資 × 3
年終獎金＝（本薪＋職務加給）× 2
```

批次計算時，依每位員工自己的常駐薪資基底分別計算。

### 比例方式

- 不按比例
- 依本期計薪比例
- 依在職日數比例
- 依實際計薪日數比例
- 逐人調整

### 批次預覽

確認加入前逐人顯示：

| 套用 | 工號 | 姓名 | 部門 | 基底 | 倍數／比例 | 計算結果 |
| ---- | ---- | ---- | ---- | ---- | ---------- | -------- |

管理者可排除或加入員工、修改個別倍數或比例、覆寫最終金額並查看無法計算原因。覆寫結果時原因必填。

## 重新生成

- 重新讀取常駐薪資、出勤、請假、加班及相關設定。
- 當期臨時項目預設保留。
- 重新生成前提示保留的臨時項目數量。
- 臨時項目不會重複建立，也不會寫回員工常駐薪資。
- 重新計算統計、員工代扣、雇主負擔與公司總成本。

## 操作流程

```text
進入當月
├─ 尚未生成 → 生成試算
└─ 已生成 → 直接顯示最新結果
   ├─ 新增／修改當期臨時薪資項目
   ├─ 重新生成
   └─ 結算 → 鎖定
      └─ 撤銷結算
         ├─ 修改
         ├─ 重新生成
         └─ 再次結算
```
